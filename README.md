<h1>Active Directory </h1>


<h2>Description</h2>
This lab consists of building a functional Active Directory lab using VirtualBox. This tutorial demonstrates setting up a domain controller, configuring network adapters, and installing essential services like DHCP. A PowerShell script automatically creates numerous user accounts.
